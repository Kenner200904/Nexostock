# NEXOSTOCK

Proyecto React 19 + TypeScript + Vite 8 + Tailwind CSS 4 exportado de Figma Make.
Conservar el diseño, componentes y lockfile existentes. Usar pnpm.

- `pnpm dev`: servidor local (no se inicia automáticamente).
- `pnpm typecheck`: comprobación TypeScript.
- `pnpm build`: genera `dist/`.
- `pnpm preview`: sirve la compilación local.

La configuración ya no depende de Figma Make. `src/App.tsx` gestiona la navegación por hash. `src/index.css` contiene los estilos globales; el alias `@` apunta a `src/`.

Esta versión es una demostración. No presentar los datos, las órdenes, el acceso o los modelos simulados como funciones de producción. Consultar README.md para el estado de cada módulo antes de extenderlo.
